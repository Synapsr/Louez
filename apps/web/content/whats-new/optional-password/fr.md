Jusqu'ici, vous vous connectiez à Louez avec un code reçu par e-mail ou avec Google. Vous pouvez maintenant ajouter un mot de passe à votre compte. C'est facultatif : le code par e-mail reste toujours disponible.

## Définir un mot de passe

Ouvrez **Mon compte**. La carte **Connexion** liste vos moyens de connexion : le code par e-mail, Google et le mot de passe. Cliquez sur **Définir**, choisissez un mot de passe d'au moins 8 caractères, et c'est fait. Un seul champ à remplir : le bouton en forme d'œil vous permet de vérifier ce que vous avez saisi.

Depuis cette même carte, vous pouvez le modifier ou le retirer à tout moment.

## Se connecter avec

Sur l'écran de connexion, cliquez sur **Se connecter avec un mot de passe**. Louez retient la méthode que vous avez utilisée : la prochaine fois, le bon écran s'ouvre directement.

## Mot de passe oublié

Cliquez sur **Mot de passe oublié ?**, saisissez le code à 6 chiffres reçu par e-mail, puis choisissez un nouveau mot de passe. Vous êtes connecté dans la foulée.

## Votre compte reste protégé

- Chaque fois qu'un mot de passe est ajouté, modifié ou retiré, vous recevez un e-mail. Si vous n'y êtes pour rien, le bouton **Ce n'était pas moi** retire le mot de passe et déconnecte tous les appareils.
- Définir ou modifier un mot de passe déconnecte vos autres appareils.
