## Build on Louez with the public API reference, in beta

The REST API's reference is now public at `/api/v1/docs` on your Louez address, with its OpenAPI document at `/api/v1/openapi.json`: every operation the API exposes, what it takes and what it answers, and how to connect with an API key from Settings > Integrations > MCP. The REST API page of your dashboard now links to it. The API is in beta, so operations may still change; every change is announced in this changelog.
